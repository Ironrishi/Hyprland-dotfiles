## 🚀 Setup

1. Install [Obsidian](https://obsidian.md/download)
2. Clone this repo:
   ```bash
   git clone git@github.com:Ironrishi/Obsidian-vault.git
   ```
3. Open Obsidian → **Open folder as vault** → select the cloned folder
4. Trust the workspace settings when prompted

---

## 🔄 Syncing

This vault is version-controlled with Git. To pull latest changes:

```bash
git pull origin main
```

To push updates:

```bash
git add .
git commit -m "update notes"
git push
```
